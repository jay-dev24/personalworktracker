# Personal Work Tracker

A full-stack MERN (MongoDB, Express.js, React.js, Node.js) application used for managing customer work records, invoice tracking, material details, PDF uploads, export functionality, and date-wise filtering.

## Features

* Customer Invoice Management
* Material Tracking
* Search Functionality
* Date Range Filters
* PDF Upload & View
* Export to Excel/PDF
* Responsive UI
* REST API Integration
* MongoDB Database Storage

## Tech Stack

### Frontend

* React.js
* CSS
* Axios
* React Icons

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
